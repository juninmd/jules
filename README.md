# Jules

A secure rate-limited Express.js server with environment configuration and input validation.

## Features

- Rate limiting to prevent abuse
- Environment variable configuration
- Input validation with express-validator
- Security headers with helmet
- CORS support
- Jest testing framework

## Installation

```bash
npm install
```

## Usage

```bash
npm start
```

## Testing

```bash
npm test
```
