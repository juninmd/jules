# Contributing to Jules

Thank you for considering contributing to Jules! Please read our contributing guidelines to help maintain the project's quality and consistency.

## Development Setup

1. Fork the repository
2. Clone your fork locally
3. Install dependencies: `npm install`
4. Create a new branch for your feature or bugfix

## Code Style

We use ESLint to maintain consistent code style. Please run the linter before submitting your code:

```bash
npx eslint src/
```

## Testing

We use Jest for testing. Please ensure your changes are covered by tests and that all tests pass:

```bash
npm test
```

## Pull Request Process

1. Update the README.md with details of changes if appropriate
2. Ensure your code passes the linter and tests
3. The CI/CD pipeline will automatically run on your pull request
4. Address any feedback from maintainers
5. Once approved, your pull request will be merged

## Reporting Issues

Please use the GitHub issue tracker to report bugs or request features.
